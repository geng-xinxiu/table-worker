# 怎么用

分两种情况，先看你手上是什么表。

## 情况一：一行一个人（最常见的表）

比如收上来的报名表、信息统计表，第一行是表头，下面一行一个人。

```
python engine/table_worker.py 你的表.xlsx --out 结果
```

跑完 `结果/` 里会有：

- `clean.xlsx` 洗过的表
- `issues.xlsx` 问题清单，一行一条，写了行号、列名、原始值、建议值
- `issues.md` 同上的文字版，可以直接发群里
- `report.md` 一页汇总
- `run.log` 过程日志

不想敲命令就把文件拖到 `one_click.ps1` 上。

### 表头不在第一行怎么办

很多表第一行是「XX班报名统计表」这种大标题，表头实际在第二行。这个程序会自己往下找，最多找 12 行。找不到就改 `rules/*.json` 里的 `header_scan_rows`。

### 列名写得不一样怎么办

「姓名」「名字」「学生姓名」这三种写法都能认，「手机号」「联系电话」「联系方式」也能认。认不出来的，在 `rules/*.json` 的 `columns.aliases` 里加一行就行。

## 情况二：列是人、行是商品（转置表）

团购、代购这类表经常这么排：A 列写商品名，后面每一列是一个人的订单，金额和付款状态也在自己那一列里。

这种不能直接跑 table_worker，要用另一个：

```
python tools/order_matrix.py 团购表.xlsx --out 结果
```

它会先转过来，然后算出：

- `orders_clean.xlsx` 一人一行，带件数、金额、付款状态、买了什么
- `items_matrix.xlsx` 商品和人的对照表，方便核对
- `reconcile.md` 对账单，谁是未付款、按金额排好
- `run.log` 日志

## 还有个小工具：挑出"还差材料的人"

有些表最后一列是自由备注，写着「需重新提交」「考核作业」「报名表」这类。这一列才是真正要动手的部分：

```
python tools/followup.py 表.xlsx --header-row 2 --remark-col 需重新提交 --out 结果
```

`--header-row` 填表头在第几行，从 1 开始数。

出来的 `followup.md` 是按原因分好组的名单，可以直接发出去。

## 规则怎么改

所有规则都在 `rules/` 下的 json 里，不用碰代码。

最常改的几项：

- `columns.required`：哪些列必填。没有手机号列的表，就把手机号去掉，否则每一行都会被报"缺失"
- `columns.whitelist`：白名单。班级名、学院名的合法写法
- `columns.dates`：哪些列要按日期处理
- `columns.numeric_ranges`：数值列的合理范围，比如绩点 0 到 5
- `rules.*`：12 条规则每条都能单独开关，`false` 就是关掉

改完直接重跑，不用重新安装任何东西。

## 输出去哪看

先看 `report.md`。一页纸，写了原始多少行、干净多少行、剔除多少、自动修了多少、要人工确认多少、总共花了多久。

然后看 `issues.xlsx`。按严重度分三档：

- 错误：数据不能用的，必须处理
- 警告：已经自动修了，确认一下方向对不对
- 提示：可能不是问题，看一眼就行

## 几个注意

表格开着 Excel 的时候跑会报错，先关掉。

有问题先看 `run.log`，每一步都记了时间戳和命中条数，能看出来卡在哪一步。

程序不联网，也不上传任何东西，只读你本地的文件。
