第一个版本。能跑通日常的表格核对。

## 这个版本有什么

- `engine/table_worker.py`：一行一个人的表，识别表头、清洗、按 12 条规则校验，出四份产物（干净表 / 问题清单 / 汇总 / 日志）
- `tools/order_matrix.py`：转置表（列是人、行是商品）的对账，算出谁买了什么、合计金额、谁还没付款
- `tools/followup.py`：从备注列里挑出"还差材料的人"，按原因分组
- `rules/标准记录表.json`：规则配置模板，换表主要改这里，不用动代码
- `one_click.ps1`：不想敲命令的话，把表格文件拖上去就跑

## 实际跑过的

自己班的团购表，13 人、22 种商品、27 行 14 列：31.9 毫秒出结果，报出原表里有两行同名商品，导致一位同学被算成两本。对账单当天发进 32 人的班级群。

自造的样例表 85 行、埋了 80 多处问题：43 条问题、约 45 毫秒。同一份输入跑两次，结果一致，只有时间戳不同。

## 已知问题

- 它只做提示，不擅自改关键字段，因为分不清"格式错"和"业务错"
- 白名单是我照自己班的情况填的，别的地方用要换掉
- 转置表的识别是启发式的，排法太怪会认错
- 没有图形界面，只有命令行和一个拖文件的脚本

## 怎么用

```
pip install openpyxl
python engine/table_worker.py samples/dirty-sample.xlsx --out out/demo
```

详细说明见 [docs/usage.md](docs/usage.md)。
