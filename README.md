# 表格工

一个把自己从表格核对里捞出来的小工具。

我是班长委，班里收团购报名表、活动报名表这类东西都是我收。收上来基本没法直接用：手机号有人少一位，日期有人写 10.21 有人写 10月21日，还有人重复交了两遍。手核一遍大概十几分钟，核完也不太敢确定自己没看漏。

上周核一张 13 个人的团购表，跑完才发现表里有两行都叫「数据结构复习题」，名字一模一样，我盯了半天没看出来，结果一个同学被算成了两本。

所以写了这个。喂进去一张 xlsx，出来四份东西：

- `clean.xlsx`：清洗过的表，能直接拿去统计
- `issues.xlsx`：哪一行哪一列有问题、建议怎么改
- `report.md`：一页纸的汇总，能直接发到群里
- `run.log`：程序自己写的过程日志，带毫秒时间戳

## 用法

```bash
pip install openpyxl

python engine/table_worker.py samples/dirty-sample.xlsx --out out/demo
```

不想敲命令的话，把表格文件拖到 `one_click.ps1` 上就行。

输出目录里会多出四个文件，打开 `report.md` 看就行。

## 里面有什么

```
engine/table_worker.py     主程序，结构识别 + 规则校验 + 出四份产物
tools/order_matrix.py      专门处理转置的订单表（列是人、行是商品那种）
tools/followup.py          从备注列里挑出"还没交材料的人"
rules/                     规则配置，换一张表主要改这里
samples/                   自己造的假数据，随便跑
```

## 关于规则

现在有 12 条规则，都能在 `rules/*.json` 里单独开关：

重复行、重复学号、重复手机号、手机号格式、学号格式、必填项缺失、姓名空格、日期格式、列名写法、数值范围、白名单、合并单元格。

自己的表不一样就改配置，不用动代码。改白名单是常见需求，比如班级名到底写「2025级1班」还是「25级1班」。

## 处理不同的表

班委的表一般两种排法：

一种是正常的，一行一个人。这个用 `table_worker.py` 直接跑。

另一种是转置的，横着是商品、竖着是人，每个人的金额和付款状态都在自己那一列。这种用 `tools/order_matrix.py`，它会先把表转过来，再算每人买了什么、一共多少钱、谁还没付。

## 一些坑

它分不清"格式错"和"业务错"。程序能告诉你这个手机号少一位，但不知道这人其实换号了。所以它只提示，不擅自改关键字段，改不改还是人决定。

白名单是我自己拍的，不是学校的正式说法。别的地方用，得换成你们自己的。

转置表的识别是猜的，认的是"第一列是属性名、后面每列一个人"。表排得不一样可能就认错了，得先看一眼。

速度快慢这种事我没法给你一个数。机器处理 13 人 22 种商品那张表用了 31.9 毫秒，但我自己确认异常、发群通知还要十分钟，省下来的其实不多。它主要帮我省的是不漏错。

## 数据

仓库里 `samples/` 那份数据是我造的，姓名是化名、手机号是 1380000xxxx 这种假号、学号也是编的。真实表格不在仓库里，也不会传上来。

程序不联网，不上传任何东西，只读本地文件。
