# 表格工 · table-worker

> 一个人 + 一套规则，把班委收表之后的核对活做完。
> 输入一张烂表，输出四件产物：**干净表 / 异常清单 / 运行日志 / 一页对账单**。

作者：耿新秀（重庆大学 微电子与通信工程学院 2025 级电子信息工程）
用途：重庆大学首届 OPC（一人公司）大学生创新创业大赛 · 赛道一 AI 软件与智能体

---

## 它能解决什么

班委手上的"烂表"通常长这样：

- 一个班里 30 多个人，手机号有人少一位、有人带空格、有人重复提交
- 日期格式五花八门：`2026/11/9`、`2026.11.9`、`11月9日`
- 表头被合并单元格搞乱，或者干脆在第二行（第一行是大标题）
- **整张表是转置的**：一行一个商品，一列一个人
- 最要命的是：同一行写了两遍，**肉眼完全看不出来**

这个工具把上述问题逐条查出来，并给出可直接执行的结论。

## 真实使用场景（已实测）

| 场景 | 表格形态 | 规模 | 结果 |
|---|---|---|---|
| 班级团购订单对账 | **转置矩阵**（列是人，行是商品） | 13 人 × 22 种商品 | 31.9 ms；检出重复商品行 1 组；生成催款名单 |

> 另外提供一份 `rules/标准记录表.json`，用于「一人一行、表头不在第一行」的普通记录表（无手机号列的场景）。
> **注意：仓库里只有上面这一单的真实使用记录，其余为自造样例。** 不把没交付过的东西写成成果。

## 五步复现

```powershell
# 0) 需要 Python 3.9+ 和 openpyxl
pip install openpyxl

# 1) 进入仓库
cd table-worker

# 2) 跑内置样例（自造脏数据，含 80+ 处问题）
python engine\table_worker.py samples\dirty-sample.xlsx --out out\demo

# 3) 看结果
#    out\demo\clean.xlsx     干净表
#    out\demo\issues.xlsx    异常清单（哪行哪列错）
#    out\demo\report.md      一页汇总
#    out\demo\run.log        机器日志（毫秒时间戳）

# 4) 不给命令也能用：把 .xlsx 拖到 one_click.ps1 上
powershell -ExecutionPolicy Bypass -File one_click.ps1 samples\dirty-sample.xlsx

# 5) 换自己的表：结构不同就改 rules\ 下的规则文件，不用改代码
python engine\table_worker.py 你的表.xlsx --out out\mine --rules rules\标准记录表.json
```

## 三个工具

| 文件 | 作用 |
|---|---|
| `engine/table_worker.py` | 主引擎：结构识别 → 清洗 → 12 条规则校验 → 四件产物 |
| `tools/order_matrix.py` | 转置订单表对账：每人一行 + 金额合计 + 已付/未付分组 + 催款名单 |
| `tools/followup.py` | 从自由备注列提炼"需跟进名单"（如"需重新提交"） |

## 12 条规则

| 编号 | 规则 | 说明 |
|---|---|---|
| R01 | 整行重复 | 同一行交了两遍 |
| R02 | 学号重复 | 两个人填了同一个学号 |
| R03 | 手机号重复 | 同上 |
| R04 | 手机号格式 | 11 位、`1[3-9]` 开头 |
| R05 | 学号格式 | 7–11 位数字，允许前缀字母 |
| R06 | 必填缺失 | 按配置的必填列判断 |
| R07 | 姓名规范 | 去空格、全角转半角 |
| R08 | 日期规范 | 多种写法统一为 `YYYY-MM-DD` |
| R09 | 列名规范 | 同义列名映射（姓名/名字/学生姓名…） |
| R10 | 数值区间 | 超出合理范围（如绩点 9.9） |
| R11 | 白名单 | 班级/学院名是否在合法清单内 |
| R12 | 表头结构 | 合并单元格展开、多行表头跳过 |

每条规则都可在 `rules/*.json` 里单独开关，**不用改代码**。

## 它做不到什么（诚实清单）

1. **分不清"格式错"和"业务错"**：能说手机号少一位，不知道这个人换号了。
2. **白名单是使用者自己拍的**，不是学校权威口径。
3. **转置表识别靠启发式**：目前认"第一列是属性、后面是人"，换个排法可能认错。
4. **不联网、不用大模型、没有训练过程**：核心是规则引擎。AI 只用于生成代码骨架与文档。
5. **没做图形界面**：目前是命令行 + 一个可拖文件的脚本。

## 数据与隐私

- 零爬虫、零系统对接、不碰任何校内系统
- 不联网、不上传、不存原始画面
- 仓库内所有样例数据均为**自造**：姓名为化名、手机号为虚拟号、学号为虚构编号
- 真实客户数据**不在本仓库中**
